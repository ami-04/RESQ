## 4. Log manipulation on the copy (§10) — scored 10 % (server-side)

Our job: produce a correctly chained, signed log **ending with a handover**. We additionally verify locally:

| Manipulation | Local finding | Test |
|---|---|---|
| change content, no new hash | `E_HASH` | `test_tamper::test_changed_field_without_new_hash` |
| change content + recomputed hash | `E_SIGNATUR` (+`E_KETTE`) | `test_changed_field_with_recomputed_hash` |
| delete entry | `E_LUECKE` + `E_KETTE` | `test_deleted_middle_event` |
| invent entry | `E_KONFLIKT` / `E_SIGNATUR` / `E_KETTE` | `test_inserted_*` |
| duplicate entry | `I_DUPLIKAT` | `test_duplicated_entry_is_reported` |
| cut off the end | `W_ENDE` | `test_truncated_end` |

## 6. Ambiguities and the conservative choice we made

| Topic | Spec says | Our decision |
|---|---|---|
| Check-in/out with a walk-in ID that was never issued | no specific `reason` | `rejected`, `reason:"other"`, ID only inside `note` (avoids `W_LOGIK` "walkin_id never registered") |
| Malformed input (empty, "HELLO") | nothing | not logged; operator sees "nothing recorded". Anything shaped like `XXX-XXX` that is not on the list → `unknown_code` with the code exactly as given (upper-cased) |
| Unknown code on paper | same rules as station | `rejected` with `source.kind:"paper"` + `occurred_at` |
| Retry after failed upload | "write handover immediately before sending" | reuse last handover if < 60 s old, else append a fresh one (keeps clock measurement honest) |
| Plausibility: "all entries of the blackout round within round time" | exact time announced Friday evening | **create the live genesis on Saturday at round start**; rehearse tonight in a separate rehearsal dir |
| Intermediate uploads | allowed | allowed, but each mid-log handover is a point where a truncated copy also ends in a handover → do the final upload last (see threat model) |
| `occurred_at` for non-paper sources | only defined for paper | never written for station/phone |
